Why we publish the 31 that came in under 98%

Because leaving them out would make the other 140 worthless. A vendor page showing nothing but perfect scores tells you only which results were selected for display. The useful number is the whole distribution: 99.04% average with a floor of 93.844% across 171 reports is a stronger statement than any single certificate, precisely because it includes the weaker ones. Every figure in the table above is recomputed from the vendor's published set each time this page rebuilds.

How to check any of this yourself

Each row below links to the report on janoshik.com — the testing lab's own domain, not a PDF hosted by the vendor and not a screenshot. That distinction is the entire point: a certificate served from the seller's own server can be anything, while a record on the lab's site was written by the lab. Match the batch code on the report to the batch code on the vial you were actually sent; a report for a different batch tells you nothing about yours.

Methodology — how this was counted

Stated plainly so anyone can reproduce it or find fault with it.

  • Source. Every page of the vendor's public lab-results index, paginated until two consecutive empty pages. No fixed page cap — an earlier version capped at 46 pages and silently under-counted as the set grew.
  • Counted on. September 5, 2026. Recounted from scratch on every rebuild, not carried forward.
  • What counts as a report. One published Janoshik entry. 228 total.
  • What counts toward the average. Only the 171 reports that state a purity figure. The remaining 57 report mass or identity without a purity percentage, so averaging them in would be inventing data.
  • Nothing is excluded for being unflattering. The 31 results below 98% and the 93.844% floor are in the average and in the downloads.
  • Not independently re-tested. We counted and computed; we did not commission our own assays. This is an audit of what is published, not a verification of the substances.
