Why we publish the 30 that came in under 98%

Because leaving them out would make the other 141 worthless. A vendor page showing nothing but perfect scores tells you only which results were selected for display. The useful number is the whole distribution: 99.04% average with a floor of 93.844% across 171 reports is a stronger statement than any single certificate, precisely because it includes the weaker ones. Every figure in the table above is recomputed from the vendor's published set each time this page rebuilds.

How to check any of this yourself

Each row below links to the report on janoshik.com — the testing lab's own domain, not a PDF hosted by the vendor and not a screenshot. That distinction is the entire point: a certificate served from the seller's own server can be anything, while a record on the lab's site was written by the lab. Match the batch code on the report to the batch code on the vial you were actually sent; a report for a different batch tells you nothing about yours.
